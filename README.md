# Insomniac

A fictional practice/portfolio site for **Insomniac**, a bakery and coffee shop open late into the night and early before sunrise — for anyone who can't sleep, works a late shift, or just needs somewhere warm to sit for a while.

> Warmth, whenever you need it.

Part of a series of practice websites built with [Claude Code](https://claude.com/claude-code), alongside [Grounded](https://github.com/FelixUnger66/grounded-coffee-shop), [Zest & Co](https://github.com/FelixUnger66/zest-and-co), and [Dexter Bowling](https://github.com/FelixUnger66/dexter-bowling).

## Structure

Plain HTML/CSS/JS, no build step.

- `index.html` — Home
- `menu.html` — Menu
- `about.html` — About
- `visit.html` — Hours, location, contact
- `css/styles.css` — shared stylesheet (design tokens + components)
- `js/main.js` — shared behavior (nav toggle, etc.)
- `images/` — photography, see `CREDITS.md`
